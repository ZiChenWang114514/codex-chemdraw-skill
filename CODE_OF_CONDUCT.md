# Code of Conduct

## Our Standard

Contributors must communicate respectfully, review technical claims on evidence, and make the project usable without harassment or discrimination. Constructive disagreement about chemistry, safety, architecture, and test quality is welcome; personal attacks, intimidation, doxxing, sexualized conduct, and deliberate disruption are not.

## Scientific and Data Conduct

Do not submit fabricated validation evidence, misrepresent unresolved structures as verified, or expose confidential chemistry and personal data. Clearly distinguish simulated fixtures from native ChemDraw, Office, model, or network verification.

## Enforcement

Repository maintainers may edit or remove contributions and restrict participation when behavior violates this policy. Report conduct concerns privately to the repository owner through GitHub. Maintainers should protect reporter privacy and apply proportionate, documented action.

This policy applies in repository spaces and when representing the project elsewhere.

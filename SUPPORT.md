# Support

Use GitHub Issues for reproducible defects and installation problems. Include:

- Windows, Codex CLI, Python, `cdxml-toolkit`, and ChemDraw versions.
- The MCP tool name and a synthetic minimal input.
- The structured error and relevant health-check output with paths and secrets redacted.
- Whether native ChemDraw, Office, local DECIMER, or remote DECIMER was involved.

Use feature requests for new public tools or workflows. Explain the end-to-end task, why existing tools are insufficient, expected inputs/outputs, overwrite behavior, privacy boundary, and how native results can be verified.

Security vulnerabilities and sensitive data must follow [SECURITY.md](SECURITY.md), not a normal issue.
